🃏 Poker Combos Probability

Um projeto em Python desenvolvido para calcular as probabilidades de formação de combinações no Poker (também chamadas de combos ou hands), como Pair, Two Pair, Three of a Kind, Straight, Flush, Full House, Four of a Kind, Straight Flush e Royal Flush.

O objetivo é fornecer uma ferramenta prática e educativa para jogadores e entusiastas do Poker compreenderem melhor as chances de cada jogada ocorrer, seja em uma partida real ou em simulações.

📌 Funcionalidades

🎲 Cálculo de probabilidades de cada mão no Poker.

🃏 Identificação de mãos a partir de cartas fornecidas.

📊 Simulação de distribuições de cartas para observar a frequência de ocorrência dos combos.

🔍 Comparação entre probabilidade teórica e probabilidade experimental (simulação).

💡 Código modular e de fácil expansão para novas regras e variações do Poker.
